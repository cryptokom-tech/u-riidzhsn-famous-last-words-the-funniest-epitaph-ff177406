Entry for the make.fun bounty [Famous Last Words: The Funniest Epitaph](https://make.fun/c/u-riidzhsn-famous-last-words-the-funniest-epitaph-ff177406): one tombstone epitaph of famous last words, at most 150 characters.

> 'It's perfectly safe,' I said. It was — for everyone standing behind me.

## Run

```bash
python3 main.py
```

`main.py` writes the epitaph to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`) and checks that the file holds exactly that line, within the 1–150 character gate. `entry.txt` in this repository is a copy of the same line.
